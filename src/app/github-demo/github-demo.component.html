ℹ️ Instructions

  1. Setup: Fill in your repository owner, repository name, and file path
  2. Create: Click "Create File" to create a new file (will fail if file exists)
  3. Fetch: Click "Fetch File" to retrieve existing file content and SHA
  4. Update: Modify content and click "Update File" (requires SHA from fetch)
  5. Smart Mode: Use "Create or Update" - automatically handles both cases
  6. Delete: Click "Delete File" to remove the file (requires SHA from fetch)

💡 Tips:

  • The GitHub token is already configured in environment.ts
  • Make sure your token has repo scope permissions
  • The "Create or Update" button is the easiest - it checks if file exists first
  • File content is automatically Base64 encoded/decoded
  • Check browser console for detailed API responses
